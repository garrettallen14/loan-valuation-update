# loan-valuation-update
 
Instructions:
1. Ensure python is installed on your machine
2. Locate this repository in your terminal
3. `python3 -m venv venv`
4. `source venv/bin/activate`
5. `pip3 install -r requirements.txt`
6. `python3 main.py`

Additional info:
- The old-repository/ folder shows the old implementation of the repository
